================================================================
TOOL 1 — Crear link de pago
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/payments/link \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100,
    "concept": "Apartado The Dream Gift",
    "order_id": "TDG-2026-0042",
    "expiration_hours": 24,
    "whatsapp_phone": "5215551234",
    "_session_id": "sess_abc123",
    "_channel_id": "ch_xyz"
  }'
Campos requeridos:  amount, concept, order_id
Campos opcionales: expiration_hours (default 24), whatsapp_phone, _session_id, _channel_id
Respuesta:
{
  "payment_id": "pay_a1b2c3d4e5f6",
  "payment_url": "https://www.mercadopago.com.mx/checkout/...",
  "expires_at": "2026-03-11T18:00:00Z"
}

TOOL 2 — Registrar comprobante de transferencia
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/payments/transfer \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100,
    "concept": "Apartado The Dream Gift",
    "order_id": "TDG-2026-0042",
    "proof_url": "https://sales-agent-ai.s3.amazonaws.com/whatsapp/media/ch_xyz/proof.jpg",
    "whatsapp_phone": "5215551234",
    "_session_id": "sess_abc123",
    "_channel_id": "ch_xyz"
  }'

Respuesta:
{
  "payment_id": "pay_tr_a1b2c3d4e5",
  "status": "pending_verification",
  "message": "Comprobante recibido. Un asesor lo verificará en breve."
}

Campos requeridos:  amount, concept, order_id, proof_url
Campos opcionales: whatsapp_phone, _session_id, _channel_id

NOTA: El pago queda en "pending_verification" hasta que el admin lo apruebe desde el panel.
      Cuando sea aprobado, el ecommerce notifica automáticamente vía callback.

  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "TDG-2026-0042",
    "photo_url": "https://sales-agent-ai.s3.amazonaws.com/whatsapp/media/ch_xyz/msg_abc.jpg",
    "_session_id": "sess_abc123",
    "_channel_id": "ch_xyz",
    "whatsapp_phone": "5215551234"
  }'

Campos requeridos:  order_id, photo_url
Campos opcionales: whatsapp_phone, _session_id, _channel_id

REQUISITO:

Respuesta:
{
  "design_id": "dsn_abc123",
  "estimated_seconds": 30
}

NOTA: El diseño se genera de forma asíncrona. El ecommerce notifica
a la plataforma vía callback cuando termina. El agente NO necesita
hacer polling — espera el evento del callback.

  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "design_id": "dsn_abc123",
    "change_notes": "El recorte quedó muy al borde, centra más la cara"
  }'

Campos requeridos:  design_id, change_notes

Respuesta:
{

  "iteration": 2,
  "estimated_seconds": 30
}

      El ecommerce notifica vía callback cuando el nuevo diseño esté listo.

TOOL 11 — Confirmar pedido (pending → in_process)
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/orders/confirm \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "TDG-2026-0042"
  }'

Campos requeridos:  order_id

Valida que el pedido tenga: product_id, design_id (diseño aprobado),
nombre, dirección completa, y que la suma de pagos aprobados cubra
el precio total del producto (rgb: $598 | madera: $719).

Respuesta:
{
  "order_id": "TDG-2026-0042",
  "status": "in_process",
  "estimated_production_days": 2,
  "estimated_delivery_days": "2-5"
}

Errores posibles:
- incomplete_order      → faltan campos, incluye "missing_fields": [...]
- design_not_approved   → el diseño no ha sido aprobado
- insufficient_payment  → total pagado no cubre el precio, incluye "paid" y "required"
