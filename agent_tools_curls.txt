  -H "Content-Type: application/json" \
  -d '{
    "amount": 100,
    "concept": "Apartado The Dream Gift",
    "order_id": "TDG-2026-0042",
    "expiration_hours": 24,
    "whatsapp_phone": "5215551234",
    "session_id": "sess_abc123",
    "channel_id": "ch_xyz"

Campos opcionales: expiration_hours (default 24), whatsapp_phone, session_id, channel_id

  "payment_url": "https://www.mercadopago.com.mx/checkout/...",
  "expires_at": "2026-03-11T18:00:00Z"

TOOL 3 — Solicitar generacion de diseno
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/designs \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "TDG-2026-0042",
    "photo_url": "https://sales-agent-ai.s3.amazonaws.com/whatsapp/media/ch_xyz/msg_abc.jpg",
    "session_id": "sess_abc123",
    "channel_id": "ch_xyz",
    "whatsapp_phone": "5215551234"
  }'

Campos requeridos:  order_id, photo_url
Campos opcionales: whatsapp_phone, session_id, channel_id

Respuesta:
{
  "design_id": "dsn_abc123",
  "estimated_seconds": 30
}

NOTA: El diseno se genera de forma asincrona. El ecommerce notifica a la plataforma via
      callback cuando termina. El agente NO necesita hacer polling, espera el evento
      del callback. El design_id queda vinculado a la orden de inmediato con
      status "processing", visible en la consulta por WhatsApp/email.

      ANTES de llamar a este endpoint, consulta los pedidos del cliente (TOOL 9 o 10)
      para verificar que la orden no tenga ya un design con status "processing" o "ready".

TOOL 5 — Solicitar revision del diseno
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/designs/revision \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "design_id": "dsn_abc123",
    "change_notes": "El recorte quedo muy al borde, centra mas la cara"
  }'

Campos requeridos:  design_id, change_notes

Respuesta:
{
  "design_id": "dsn_abc123",
  "iteration": 2,
  "estimated_seconds": 30
}

NOTA: Se reutiliza el mismo design_id. La iteracion se incrementa.
      El historial de cambios se acumula y se aplica junto con la imagen
      anterior como contexto para la IA en cada revision.
      El ecommerce notifica via callback cuando el nuevo diseno este listo.

  }'

Campos requeridos:  whatsapp_phone

Respuesta:
{
  "order_id": "TDG-2026-0042",

      ANTES de crear una orden nueva, consulta TOOL 9 para verificar
      que el cliente no tenga ya una orden activa.

================================================================
TOOL 8 — Confirmar pedido (pending -> in_process)
================================================================
curl -X POST https://api.thedreamgiftmx.com/api/orders/confirm \
  -H "Authorization: Bearer 9d4bIE7jocSGpk1vj6wZmUHri50ylpMsOQkfdsGPzruBCXz7fYJ6kjIIeV4IUYDT" \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "TDG-2026-0042"
  }'

Campos requeridos:  order_id

Valida que el pedido tenga: product_id, design aprobado, nombre,
direccion completa, y que los pagos aprobados cubran el precio total
(rgb: $597 MXN | madera: $719 MXN).

Respuesta:
{
  "order_id": "TDG-2026-0042",
  "status": "in_process",
  "estimated_production_days": 2,
  "estimated_delivery_days": "2-5"
}

Errores posibles:
- incomplete_order      -> faltan campos, incluye "missing_fields": [...]
- design_not_approved   -> el diseno no ha sido aprobado
- insufficient_payment  -> total pagado no cubre el precio, incluye "paid" y "required"

          "method": "mercadopago",
          "concept": "Apartado The Dream Gift",
          "amount": 100.0,
          "status": "approved"
        }
      ],
      "paid_total": 100.0,
      "price_required": 597.0,
      "payment_complete": false,
      "full_name": "Maria Garcia Lopez",
      "address": null,
      "city": null,
      "state": null,
      "zip_code": null,
      "email": null,
      "engraving_text": null,

design.status posibles: processing | ready | failed | null (aun no hay diseno)
order.status posibles:  pending | in_process | shipped | delivered | cancelled

      Si design.status = "ready"      -> el diseno esta listo, NO crear otro.
      "missing_fields" indica que falta para poder llamar a confirm.
      "ready_to_confirm": true cuando no falta nada.
